# Lengura Reader

A local study-site prototype for Lengura German video lessons at levels A2, B1, and B2.

## Open the site

Run `./outputs/start-local.sh` from a terminal, then open [http://127.0.0.1:8765/catalog.html](http://127.0.0.1:8765/catalog.html).

The catalog offers level filters and links to 15 Lengura lessons. The bilingual reader places the video on the left and the German transcript with English translations beneath each turn on the right. The current reader for “Conversation in German B1–B2” is an 18-turn opening excerpt; the project brief records full-transcript coverage as a completion expectation.

See [the project brief](PROJECT_BRIEF.md) and [the outputs README](outputs/README.md) for scope and operating details.
